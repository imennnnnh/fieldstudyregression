# 桌球發球機落點預測系統

輸入仰角角度、左右位置、旋球角度、出球強度，估計球落在桌內時的 X、Y 座標。落點估計可帶小數，實際發球是否有效以實測為準。

## Windows 啟動

在專案根目錄開啟 PowerShell，使用 Python 3.14 建立虛擬環境並安裝鎖定版本。已建立環境時，可直接執行安裝和啟動指令。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --workers 1
```

開啟 [http://127.0.0.1:8000](http://127.0.0.1:8000)。單一 worker 讓訓練任務、執行進度和正式模型共用同一份狀態。關閉時在終端機按 `Ctrl+C`。

## 操作流程

1. 在「模型訓練」選取一份或多份實測 `.xlsx`，按「啟動訓練」。每批使用當次選取的全部檔案。合併歷史資料與新資料時，請一次選齊。開始五折前，有效球須涵蓋至少五組不同四參數。
2. 訓練完成後，在「五折整批評估報表」查看球數、每軸分布、5×5 落點表、覆蓋提示、Pearson 相關係數、分組方式、各折資料量、各候選 MSE、兩軸勝者及整球誤差。落點表左上為 (1,1)，右下為 (5,5)。每格顯示有效球數及不同四參數組數。相關係數色階固定為 −1 至 1，常數欄位顯示「無法計算」。
3. 在「單球預測」輸入四參數。預測後，可選填或修改實測結果。有效實測會立即更新兩軸絕對誤差及雙軸距離。
4. 在「正式模型獨立測試」選取一份同格式的實測 `.xlsx`，按「開始評估」。請使用未參與本批訓練及選模的實測檔。報表會列出檔名、正式模型批次、有效／無效／缺測球數，以及有效球的迴歸誤差。正式模型更新後，請重新評估。

## Excel 格式

每份檔案至少要有一張合格工作表。表頭位於第一列，以下 10 個欄位可調整順序。

| 欄位 | 格式 |
| --- | --- |
| 測試編號 | 原始紀錄編號，供回查 |
| 仰角角度 | 整數 1～28 |
| 左右位置 | 整數 1～9 |
| 旋球角度 | 整數 1～59 |
| 出球強度 | 整數 1～99 |
| 發球1_落點 至 發球5_落點 | 半形座標 `(x,y)`，X、Y 皆為 1～5 的整數，或下列指定無效文字 |

「碰桌後彈出」「飛出台面」「未過網」「球碰網後沒有進入有效區」記為無效球。空白、Excel 字面 `(0,0)`、混合零座標和其他無法辨識的落點記為缺測。四參數完整但五球落點皆空白的資料列記為五個缺測球位。四參數與落點欄位皆空白的列會略過。欄位錯誤會指出檔名、工作表、列號及欄位。每列的落點逐球處理，同列可同時包含有效、無效及缺測。只有 X、Y 皆在 1～5 的實測球會進入迴歸。

## 如何解讀成績

- 分組鍵是完整四參數。即使測試編號、工作表或檔案不同，同組的有效球也會同折。以 25 個落點格做 StratifiedGroupKFold 分層。若每格都少於五顆球，或分層產生的切分未通過驗證，改用 GroupKFold，報表會顯示原因。
- 每折訓練 RFx、ETx、RFy、ETy，總共 20 次。以每折同權的五折平均 MSE 分別選出 X、Y 勝者。同分時 RF 優先。各折基準線使用該折訓練球的 X、Y 平均座標，僅供比較。
- 整批留出球的誤差每球同權。兩軸 MAE、RMSE 及雙軸距離的單位是格，MSE 的單位是格²。雙軸平均歐氏距離先算每顆球的落點直線偏差，再取平均。雙軸 RMSE 為 `sqrt(MSE_X + MSE_Y)`。五折同時用於選模，正式 X、Y 模型再用本批 100% 有效球分別重訓。正式模型的表現以另備的獨立測試評估。
- 同一四參數設定重新實測，可評估該設定再次發球的表現。若要評估未見設定，請選用訓練資料未涵蓋的四參數組合。若測試檔混有兩種設定，整批成績會涵蓋兩種情況。

## 保存與測試

原始工作簿及原檔名存於 `data/uploads/<run_id>/`。已發布的 `data/artifacts/<run_id>/` 包含 X、Y 模型、`report.json` 與每顆留出球一列的 `fold_predictions.csv`。兩軸模型及報表完整驗證後才更新 `latest_success.json`。新批次訓練中或失敗時，上一批成功的迴歸模型及報表仍可使用。分類版成果保留於原處。

自動測試使用隔離的 `runtime/` 目錄。從專案根目錄執行。

```powershell
$testTemp = New-Item -ItemType Directory -Force runtime/tmp
$env:TMP = $env:TEMP = $testTemp.FullName
.\.venv\Scripts\python.exe -B -m unittest backend.test_system -v
```
